# Security Policy

ProofMesh está en desarrollo activo. Para reportar una vulnerabilidad, no abras una issue pública con detalles explotables; utiliza GitHub Security Advisories o contacta de forma privada con los mantenedores.

Incluye versión, pasos de reproducción, impacto, evidencia y una mitigación propuesta si está disponible. Las auditorías de ProofMesh no sustituyen controles de seguridad especializados en sistemas críticos.
