# Contribuir a ProofMesh

Antes de abrir un pull request, ejecuta `pnpm check`, `pnpm test` y `pnpm build`. Los cambios del motor deben incluir pruebas que cubran aprobación 10/10 y rechazo por cualquier fallo de criterio, nodo o nivel.

Las nuevas reglas deben explicar su evidencia, evitar secretos o datos personales y conservar el contrato JSON. La interfaz debe mantener el lenguaje visual de ProofMesh: verde de autoridad, crema de trabajo y coral reservado para acción o riesgo.
